# Sistema de Gestão para Escola de Música

## Descrição
Sistema desenvolvido para gerenciamento de alunos, cursos, professores e financeiro de uma escola de música.

## Funcionalidades
- Cadastro de alunos
- Cadastro de professores
- Controle de cursos
- Registro de aulas
- Controle de presença
- Gestão financeira

## Tecnologias
- Java
- MySQL
- JDBC / JPA

## Banco de Dados
O sistema utiliza um modelo relacional com tabelas como:
- Alunos
- Professores
- Cursos
- Aulas
- Presença
- Financeiro
